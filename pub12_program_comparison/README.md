# pub12_program_comparison

Working title of the manuscript: Same name, different threshold call: QRS and QTc classification across ECG programs and public datasets

Scripts behind the comparison of threshold calls of several ECG programs on the same PTB-XL recordings, the disagreement between two programs against the scatter between repeat recordings of one person, the definition audit, and the benchmark harness that ran the programs.

## Data and inputs

PTB-XL 1.0.3 and PTB-XL+ 1.0.1, LUDB 1.0.1, EchoNext 1.1.1 (aggregate analysis only). Program outputs of 12SL and Uni-G come from PTB-XL+; BRAVEHEART, NeuroKit2 and ECGDeli are run by the benchmark scripts; LoopLens output comes from the snapshot in `../looplens_snapshot_2026-10-07/`. None of these data is part of this repository. Set the locations in `config.toml` (see the root `README.md`); the keys used by this folder start with `pub12.` in `config.example.toml`.

## Scripts

61 files: 1 original and unchanged, 21 cleaned originals, 39 translated. The status column uses the three terms explained in the root README; cleaned originals and translated files received some of five edit types: paths replaced by data_path, user or cloud-folder names removed, long dashes replaced, unpublished expected values moved to the local reference file, unpublished numbers removed from texts. The last column names the part of the manuscript or supplement whose numbers depend on the script, as far as it could be traced (`support module` = used by other scripts; `not traceable` = no reported item found). Folder names are descriptive; the scripts themselves keep their original file names because they import each other by name.

* All data, result tables, intermediate files and the local reference-value file.
* The unpublished expected values of 7 scripts: they were moved to a local file that is not published (see the root README, section Running the scripts).

## Reproducing the numbers

The numbers are in the manuscript tables and the supplement. To reproduce an analysis, obtain the data, produce the LoopLens output tables with the snapshot, fill `config.toml` and adapt the scripts to your layout. Random seeds are set in the scripts and marked as such.
