# b_qrs_t_coupling

Working title of the manuscript: Does QRS-T loop coupling add to the QRS-T angle? Frechet distance and reduced ejection fraction in hospital ECGs, with named measurement-error scenarios

Scripts behind the association analysis of a Frechet-distance marker with reduced left ventricular ejection fraction: development and assessment partitions, measurement-error corrections (regression calibration, SIMEX), tipping and sensitivity analyses, differential-missingness checks and the figures.

## Data and inputs

MIMIC-IV-ECG 1.0, MIMIC-IV 3.1 (hosp module) and MIMIC-IV-ECHO 1.0 for the outcome; LUDB 1.0.1 for boundary errors only. The marker values are LoopLens output produced with the snapshot in `../looplens_snapshot_2026-10-07/`. None of these data is part of this repository. Set the locations in `config.toml` (see the root `README.md`); the keys used by this folder start with `b.` in `config.example.toml`.

## Scripts

103 files: 23 original and unchanged, 52 cleaned originals, 28 translated. The status column uses the three terms explained in the root README; cleaned originals and translated files received some of five edit types: paths replaced by data_path, user or cloud-folder names removed, long dashes replaced, unpublished expected values moved to the local reference file, unpublished numbers removed from texts. The last column names the part of the manuscript or supplement whose numbers depend on the script, as far as it could be traced (`support module` = used by other scripts; `not traceable` = no reported item found). Folder names are descriptive; the scripts themselves keep their original file names because they import each other by name.

## What is not in this folder

* Self-tests and unit tests of the analysis code, download helpers and packaging of the manuscripts (not part of the reported analyses).
* All data, result tables, intermediate files and the local reference-value file.
* The unpublished expected values of 2 scripts: they were moved to a local file that is not published (see the root README, section Running the scripts).
* Modules shared with other works are in `../shared_support/`.

## Reproducing the numbers

The numbers are in the manuscript tables and the supplement. To reproduce an analysis, obtain the data, produce the LoopLens output tables with the snapshot, fill `config.toml` and adapt the scripts to your layout. Random seeds are set in the scripts and marked as such.
